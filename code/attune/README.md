Firebase
Firebase is a backend platform made by Google that gives you a database, authentication, file storage, and more — all hosted in the cloud, so you don't have to build or manage a server yourself. For a Flutter app like yours it handles three things:
Firebase Auth — lets users sign up / log in with email & password (or Google, etc.) without you writing any auth logic from scratch.
Firestore — a NoSQL cloud database where you store all your app's data (users, albums, ratings, comments). It works like a big nested JSON structure organized into collections and documents. For example: /users/{uid} would be a document holding one user's profile info.
Why it's popular for class projects — there's a generous free tier, the Flutter SDK is excellent, and it syncs data in real time (great for things like a live leaderboard).
The alternative would be something like Supabase (which uses SQL instead) or building your own REST API — but Firebase is the fastest to get running.
